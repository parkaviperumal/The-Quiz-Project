# Python Quiz Application

A simple True/False quiz application developed using Python.

## Features

- 10 True/False questions
- User name input
- Score calculation
- Percentage calculation
- Pass/Fail result
- Simple command-line interface

## Technologies Used

- Python

## Project Structure

- main.py - Runs the quiz application
- data.py - Contains quiz questions and answers
- questions_model.py - Defines the Question class
- quiz_brain.py - Handles quiz logic and score calculation

## How to Run

1. Download or clone this repository.
2. Make sure all Python files are in the same folder.
3. Run main.py.
4. Enter your name and answer the questions using True or False.
